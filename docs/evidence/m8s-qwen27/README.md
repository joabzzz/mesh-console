# Live Qwen 27B desktop demo

[Watch the 67-second demo](demo.mp4).

Qwen 27B chat turns, and provider-confirmed removal. Startup waits are shortened
and labeled; the conversation is held briefly for readability.

The actual desktop frontend is captured against the running Tauri backend,
without the native window frame. This prototype uses a dedicated demo mesh.
The uncut recording is retained locally and is not included in this PR.
